Implementación del sistema de visualización de CLUES

Este sistema permite visualizar y analizar el número de CLUES por entidad federativa,
tanto en una gráfica de barras interactiva con ApexCharts como en una tabla dinámica
con DataTables. 

 Funcionalidades principales:
- Gráfica de barras con ApexCharts para mostrar la cantidad de CLUES por entidad.
- Tabla dinámica con DataTables, con paginación, búsqueda y ordenamiento.
- Filtro de entidades mediante un input select, que actualiza la gráfica y la tabla.
- Actualización dinámica de datos al cambiar la entidad seleccionada.
- Consumo de APIs en PHP con el patrón MVC para obtener la información desde MySQL.

 Tecnologías utilizadas:
- PHP (Back-end con modelo MVC)
- MySQL (Base de datos para almacenar CLUES)
- JavaScript (Interacción dinámica con fetch API)
- ApexCharts (Gráficos de visualización)
- DataTables (Manejo de datos en tabla)
- Bootstrap (Diseño moderno y responsivo)
